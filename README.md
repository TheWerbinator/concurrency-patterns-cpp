# concurrency-patterns-cpp

Modern C++20 implementations of the canonical concurrency problems —
race conditions, producer/consumer, dining philosophers, reader/writer,
semaphores, fork race — with ThreadSanitizer + AddressSanitizer in CI.

Portfolio rewrite of **CS 3600 (Operating Systems)** assignments from
Southern Utah University, ported from mixed C/pthread to modern C++20
primitives.

🚧 Work in progress.
